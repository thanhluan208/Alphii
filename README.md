# 📦 Next.js 14 Project

This is a [Next.js 14](https://nextjs.org/) application using the App Router, React Server Components, and modern web features.

## 🚀 Features

- App Router & Layouts  
- React Server Components  
- SEO-optimized  
- TypeScript support (optional)  
- Ready for API integration  

## 🧰 Requirements

- Node.js v18 or later  
- npm or yarn  

## 📦 Installation

```bash
# Using npm
npm install

# Or using yarn
yarn install

# Start the development server
npm run dev
# or
yarn dev

# Build the app
npm run build
# or
yarn build

# Start the production server
npm start
# or
yarn start


# Lint the code
npm run lint
# or
yarn lint
